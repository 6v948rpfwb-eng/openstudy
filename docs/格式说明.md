# 题库格式说明

## 顶层结构

```json
{
  "subject": "physics",
  "title": "高中物理",
  "version": 1,
  "topics": { "P-01": { "name": "匀变速直线运动", "desc": "可选说明" } },
  "questions": [ ... ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `subject` | 是 | 学科代号，只能用小写字母/数字/连字符，用来区分进度文件 |
| `title` | 否 | 显示名 |
| `version` | 否 | 格式版本，目前都是 1 |
| `topics` | 是 | 考点表，键是考点编号 |
| `questions` | 是 | 题目数组，不能为空 |

## 题目字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 全局唯一 |
| `topic` | 是 | 必须是 `topics` 里的键 |
| `type` | 是 | `numeric` / `choice` / `text` |
| `difficulty` | 是 | `[0,1]` 的数，越大越难 |
| `stem` | 是 | 题干，支持换行 |
| `answer` | 是 | 见下 |
| `solution` | 否 | 解析，答错时显示 |
| `source` | **是** | 出处。**不填会被拒绝加载** |
| `choices` | choice 必填 | 选项数组 |

## difficulty 怎么定

难度是主观的，但必须**在同一个题库内部保持相对一致**，否则组卷会失衡。建议：

| 值 | 含义 | 大致对应 |
|---|---|---|
| 0.05–0.20 | 看一眼就会 | 概念复述 |
| 0.20–0.35 | 直接套公式 | 一步计算 |
| 0.35–0.50 | 需要想一下用哪个公式 | 两步计算 |
| 0.50–0.65 | 需要拆解或画图 | 多过程 |
| 0.65–0.80 | 需要综合多个考点 | 压轴前半 |
| 0.80–1.00 | 竞赛边缘 / 需要巧法 | 压轴 |

**关键不是绝对值准，而是相对顺序对。** 引擎只关心题与题之间的难度关系。

## 三种题型

### numeric —— 数值题

```json
{
  "id": "q001", "topic": "P-01", "type": "numeric", "difficulty": 0.45,
  "stem": "一物体从静止开始以 2 m/s² 加速，4 s 后速度多大？",
  "answer": { "value": 8, "relTol": 0.01 },
  "solution": "v = at = 2 × 4 = 8 m/s",
  "source": "2024年浙江卷第12题"
}
```

`answer` 的可选字段：

- `value`：数字，或多空时用数组 `[6, 8]`
- `relTol`：相对容差，默认 0.01（1%）
- `tol`：绝对容差，优先于 `relTol`

学生填 `8`、`8.0`、`8 m/s` 都判对（会从文本里抽出唯一数字）。
填 `8.05` 在 1% 容差内（8 × 0.01 = 0.08）也判对。

**多空题**：

```json
"answer": { "value": [6, 2] }
```

学生必须填两个数，顺序对应。

### choice —— 选择题

```json
{
  "id": "q002", "topic": "P-01", "type": "choice", "difficulty": 0.30,
  "stem": "下列哪个是矢量？",
  "choices": ["路程", "位移", "时间", "质量"],
  "answer": { "value": 1 },
  "source": "示例"
}
```

`answer.value` 是**从 0 起**的下标。上例正确答案是「位移」= 下标 1。

多选：`"answer": { "value": [0, 2] }`

### text —— 主观题

```json
{
  "id": "q003", "topic": "P-01", "type": "text", "difficulty": 0.80,
  "stem": "证明匀变速直线运动的平均速度等于初末速度的平均值。",
  "answer": { "reference": "设初速 v0、末速 v、加速度 a、时间 t..." },
  "source": "2023年浙江卷第18题"
}
```

**不做自动判分**。网页上会显示参考答案，让你自己点「对了 / 半对 / 错了」。
自评结果只进考点记录，**不进能力估计 θ**——因为自评不可靠，不能拿它推翻客观题的结论。

## 校验规则

加载时会检查，出现下列任何一条就拒绝加载：

1. 缺 `subject` / `topics` / `questions`
2. `id` 重复
3. `topic` 不在 `topics` 表里
4. `difficulty` 不在 `[0,1]`
5. 缺 `source`
6. `numeric` 题 `answer.value` 不是数字
7. `choice` 题正确下标越界
8. `type` 不是三种之一

只警告不阻止的情况：

- 某考点一道题都没有
- 某考点少于 3 道题（组卷时会重复抽到）
- 没有 `solution`
- `text` 题没有参考答案
